# Candidate must-refuse questions.
#
# One per line. Terms are derived from the question's content words; add any
# word the handbooks might use instead after a pipe, comma separated.
#
#   sweep:  python refuse_candidates.py
#   read:   docs/refuse-sweep.md
#
# A candidate is NOT a question yet. It becomes one when you have read every
# passage the sweep prints under it and written KEEP or DROP on its verdict
# line. Target is five KEEPs; the DROPs are worth as much, because they are
# the labels that did not ship.
#
# Three shapes, in increasing order of value to the eval:
#
#   A. out of scope      nothing a parent handbook would ever contain
#   B. absent            ordinary parent question these four never address
#   C. never stated      the topic is everywhere, the specific fact is absent
#
# C is the one the refusal finding rests on: high lexical overlap, no answer.
# It is also the shape that produced every mislabel so far, which is why it
# gets swept and read instead of guessed.
#
# None of these duplicates an existing question. A near-duplicate of a row
# already in the set does not add resolution, it adds a correlated pair.
